# 中间件管理脚本使用指南

## 快速开始

```bash
cd /home/lihaoqian/project/clouddisk_v2/scripts

# 查看帮助
./manage-infra.sh help

# 启动所有服务
./manage-infra.sh start

# 查看服务状态
./manage-infra.sh status
```

## 命令说明

### 1. 启动服务

```bash
# 启动所有服务
./manage-infra.sh start

# 启动单个服务
./manage-infra.sh start mysql
./manage-infra.sh start redis
./manage-infra.sh start minio
./manage-infra.sh start nacos
./manage-infra.sh start consul
./manage-infra.sh start kafka
./manage-infra.sh start zookeeper
```

### 2. 停止服务

```bash
# 停止所有服务
./manage-infra.sh stop

# 停止单个服务
./manage-infra.sh stop mysql
./manage-infra.sh stop nacos
```

### 3. 重启服务

```bash
# 重启所有服务
./manage-infra.sh restart

# 重启单个服务
./manage-infra.sh restart mysql
./manage-infra.sh restart nacos
```

### 4. 查看状态

```bash
# 查看所有服务状态
./manage-infra.sh status

# 查看单个服务状态
./manage-infra.sh status mysql
```

### 5. 查看日志

```bash
# 查看服务日志（实时）
./manage-infra.sh logs mysql
./manage-infra.sh logs nacos
./manage-infra.sh logs kafka

# 按 Ctrl+C 退出日志查看
```

## 服务列表

| 服务名 | 说明 | 端口 |
|--------|------|------|
| mysql | MySQL 数据库 | 30306 |
| redis | Redis 缓存 | 30379 |
| minio | MinIO 对象存储 | 30900, 30901 |
| nacos | Nacos 配置中心 | 30848, 30880, 31848 |
| consul | Consul 服务发现 | 30500 |
| kafka | Kafka 消息队列 | 31092 |
| zookeeper | Zookeeper | 2181 |

## 常见场景

### 场景 1: 首次部署

```bash
# 1. 启动所有服务
./manage-infra.sh start

# 2. 等待服务启动（约 30 秒）
sleep 30

# 3. 查看状态
./manage-infra.sh status

# 4. 如果某个服务未启动，查看日志
./manage-infra.sh logs nacos
```

### 场景 2: 重启单个服务

```bash
# 重启 Nacos
./manage-infra.sh restart nacos

# 查看日志确认启动
./manage-infra.sh logs nacos
```

### 场景 3: 停止所有服务（节省资源）

```bash
# 停止所有服务
./manage-infra.sh stop

# 需要时再启动
./manage-infra.sh start
```

### 场景 4: 调试问题

```bash
# 1. 查看服务状态
./manage-infra.sh status

# 2. 查看问题服务的日志
./manage-infra.sh logs mysql

# 3. 重启问题服务
./manage-infra.sh restart mysql

# 4. 再次查看日志
./manage-infra.sh logs mysql
```

### 场景 5: 更新配置后重启

```bash
# 修改 YAML 配置文件后
vim mysql-deployment.yaml

# 重启服务使配置生效
./manage-infra.sh restart mysql
```

## 服务启动顺序

脚本会按照以下顺序启动服务（考虑依赖关系）：

1. Namespace（命名空间）
2. MySQL（数据库）
3. Redis（缓存）
4. MinIO（对象存储）
5. Consul（服务发现）
6. Zookeeper（Kafka 依赖）
7. Kafka（消息队列）
8. Nacos（配置中心，依赖 MySQL）
9. Services（端口映射）

停止时会按相反顺序执行。

## 访问地址

启动后，可以通过以下地址访问服务：

```bash
# 获取本地 IP
LOCAL_IP=$(hostname -I | awk '{print $1}')

# 访问地址
echo "Nacos Console: http://${LOCAL_IP}:30848/nacos"
echo "MinIO Console: http://${LOCAL_IP}:30901"
echo "Consul UI:     http://${LOCAL_IP}:30500"
echo "MySQL:         ${LOCAL_IP}:30306"
echo "Redis:         ${LOCAL_IP}:30379"
echo "Kafka:         ${LOCAL_IP}:31092"
```

或者直接运行：

```bash
./manage-infra.sh status
```

会自动显示访问地址。

## 故障排查

### 问题 1: 服务启动失败

```bash
# 查看详细日志
./manage-infra.sh logs <service_name>

# 查看 Pod 详情
kubectl describe pod -n infra -l app=<service_name>

# 重启服务
./manage-infra.sh restart <service_name>
```

### 问题 2: 无法连接服务

```bash
# 检查服务状态
./manage-infra.sh status

# 检查端口是否正确
kubectl get svc -n infra

# 检查防火墙
sudo ufw status
```

### 问题 3: Nacos 启动失败

```bash
# 检查 MySQL 是否正常
./manage-infra.sh status mysql

# 检查数据库是否初始化
kubectl exec -it -n infra $(kubectl get pod -n infra -l app=mysql -o jsonpath='{.items[0].metadata.name}') -- \
  mysql -uroot -p123456 -e "SHOW DATABASES;"

# 重新初始化数据库
./init-nacos-db.sh

# 重启 Nacos
./manage-infra.sh restart nacos
```

## 高级用法

### 批量操作

```bash
# 重启所有数据存储服务
for service in mysql redis minio; do
    ./manage-infra.sh restart $service
    sleep 5
done

# 查看所有服务日志（最后 20 行）
for service in mysql redis nacos; do
    echo "=== $service ==="
    kubectl logs -n infra -l app=$service --tail=20
done
```

### 监控服务

```bash
# 实时监控所有 Pod 状态
watch -n 2 './manage-infra.sh status'

# 或使用 kubectl
watch -n 2 'kubectl get pods -n infra'
```

### 备份和恢复

```bash
# 备份 MySQL
kubectl exec -n infra $(kubectl get pod -n infra -l app=mysql -o jsonpath='{.items[0].metadata.name}') -- \
  mysqldump -uroot -p123456 --all-databases > backup-$(date +%Y%m%d).sql

# 恢复 MySQL
kubectl exec -i -n infra $(kubectl get pod -n infra -l app=mysql -o jsonpath='{.items[0].metadata.name}') -- \
  mysql -uroot -p123456 < backup-20260305.sql
```

## 性能优化

### 调整资源限制

编辑 YAML 文件，添加资源限制：

```yaml
resources:
  requests:
    memory: "512Mi"
    cpu: "500m"
  limits:
    memory: "1Gi"
    cpu: "1000m"
```

然后重启服务：

```bash
./manage-infra.sh restart <service_name>
```

### 调整副本数

```bash
# 扩展 Redis 副本
kubectl scale deployment redis -n infra --replicas=3

# 查看状态
./manage-infra.sh status redis
```

## 完全清理

如果需要完全清理所有服务：

```bash
# 停止所有服务
./manage-infra.sh stop

# 删除 namespace（会删除所有资源）
kubectl delete namespace infra

# 删除 PV（如果需要）
kubectl delete pv --all
```

---

**提示：** 建议将此脚本添加到系统 PATH 或创建别名：

```bash
# 添加别名到 ~/.bashrc
echo "alias infra='cd /home/lihaoqian/project/clouddisk_v2/scripts && ./manage-infra.sh'" >> ~/.bashrc
source ~/.bashrc

# 然后可以在任何目录使用
infra status
infra start mysql
infra logs nacos
```
